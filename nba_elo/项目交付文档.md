## 📊 项目概述

### 项目名称
九麦NBA范特西联赛 ELO排名系统

### 项目目标

### 完成日期

## ✅ 已交付功能

### 核心功能
1. **ELO排名系统**
   - 实时计算球员ELO分数
   - 支持多联赛（5个联赛，80支球队）
   - 历史数据追踪
   - 胜率统计

2. **数据展示平台**
   - 首页：ELO排行榜（前100名）
   - 联赛列表：5个联赛概览

   - 球队阵容：14名球员详细信息

3. **数据更新机制**
   - 本地脚本获取Yahoo数据
   - 手动上传到服务器
   - 实时网站展示

## 🏗️ 系统架构

### 技术栈
```
前端：HTML + CSS（响应式设计）
后端：Python Flask
数据库：SQLite
服务器：Nginx + Gunicorn + Supervisor
部署：腾讯云 Lighthouse (Ubuntu 22.04)
```

## 🌐 服务器配置

### 基本信息

- **操作系统：** Ubuntu 22.04 LTS
- **配置：** 2核CPU, 4GB内存
- **访问地址：** http://129.204.8.241

### 服务配置

**Nginx配置：** `/etc/nginx/sites-available/nba_elo`
```nginx
server {
    listen 80;
    server_name 129.204.8.241;
    
    location / {
        proxy_pass http://127.0.0.1:8000;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
    }
    
    location /static {
        alias /var/www/nba_elo/static;
    }
}
```

**Gunicorn配置：** `/etc/supervisor/conf.d/nba_elo.conf`
```ini
[program:nba_elo]
command=/var/www/nba_elo/venv/bin/gunicorn app:app -b 127.0.0.1:8000 -w 2
directory=/var/www/nba_elo
user=ubuntu
autostart=true
autorestart=true
stdout_logfile=/var/log/nba_elo.out.log
stderr_logfile=/var/log/nba_elo.err.log
```

## 🚨 故障排查

### 常见问题速查表

| 问题 | 可能原因 | 解决方法 |
|------|---------|---------|
| 网站无法访问 | Nginx/Gunicorn停止 | `sudo supervisorctl restart nba_elo` |
| 显示旧数据 | 数据库未更新 | 重新上传 nba_elo.db |
| Roster页面错误 | JSON文件缺失 | 上传 roster_data.json |
| Token过期 | Yahoo认证过期 | 重新运行授权脚本 |

### 日志位置
- **应用日志：** `/var/log/nba_elo.err.log`
- **Nginx日志：** `/var/log/nginx/error.log`
- **访问日志：** `/var/log/nginx/access.log`
