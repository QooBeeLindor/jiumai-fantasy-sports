# 九麦NBA蛇形选秀联赛 - 项目管理

## 🎯 项目目标

构建一个完整的蛇形选秀联赛数据管理和展示系统，支持：
- 12个联赛的数据采集和统计
- 选秀数据分析（ADP）
- 比赛记录追踪
- 交易数据统计（FA排行）
- Roto积分排行系统
- 历史赛季存档

## 📁 文件组织规范

### 核心代码（提交到Git）

```
draft_league/NBA/
├── scripts/          # 所有Python脚本
├── web/             # 前端文件
├── database/        # 只提交schema.sql
├── data/            # 只提交配置文件
├── api.py
├── requirements.txt
├── README.md
└── .gitignore
```

### 不提交到Git

- `database/*.db` - 数据库文件
- `config/oauth2.json` - API认证
- `data/*.xlsx` - 数据文件
- `__pycache__/` - Python缓存
