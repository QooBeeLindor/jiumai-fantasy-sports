## 🚀 标准更新流程（3个命令）

### 在你的Windows电脑上

**打开PowerShell或CMD，输入：**

```bash

```

**输入密码后，继续输入：**

```bash
cd /var/www/ironman && source venv/bin/activate && python sync_yahoo_standings.py ironman.db oauth2.json && sudo supervisorctl restart ironman
```

**完成！** 刷新浏览器就能看到新数据。

## ⚠️ 常见维护问题

### Q1: 同步时显示"Token已过期"

**A:** OAuth令牌过期了，需要重新认证

```bash
cd /var/www/ironman
source venv/bin/activate
python test_yahoo_api.py oauth2.json
```

会打开浏览器让你重新授权。

### Q2: 某些玩家数据没更新

**A:** 可能是队名变了

```bash
# 查看哪些队名没匹配上
python sync_yahoo_standings.py ironman.db oauth2.json
# 看输出中的"未匹配队伍"

# 如果有未匹配的，运行修复工具
python fix_team_names_from_yahoo.py ironman.db
```

### Q3: 网页打不开了

**A:** 检查服务状态

```bash
sudo supervisorctl status ironman

# 如果是STOPPED，启动它
sudo supervisorctl start ironman

# 查看错误日志
sudo tail -50 /var/log/ironman.err.log
```

### Q4: 数据库损坏

**A:** 从本地重新上传

```bash
# 在本地确保数据正确
python check_database.py ironman.db

# 上传到服务器 /tmp/
# 然后在服务器上
sudo cp /tmp/ironman.db /var/www/ironman/ironman.db
sudo supervisorctl restart ironman
```

## 🎯 自动化维护（可选）

### 设置定时任务（Crontab）

```bash
# 编辑crontab
crontab -e

# 添加这一行（每天凌晨2点自动更新）
0 2 * * * cd /var/www/ironman && source venv/bin/activate && python sync_yahoo_standings.py ironman.db oauth2.json && sudo supervisorctl restart ironman

# 保存退出（按Esc，输入:wq，回车）
```

**好处：** 每天自动更新，不用手动操作

**坏处：** 如果Yahoo API有问题，可能会静默失败

**建议：** 每周还是手动检查一次
