## 🚀 每周维护（5分钟）

### 方法1: 使用管理脚本（推荐）

**首次设置：**
```bash
# 1. SSH连接
ssh ubuntu@129.204.8.241

# 2. 上传管理脚本到服务器
# (使用WinSCP上传 manage_irongroup.sh 到 /var/www/irongroup/)

# 3. 设置权限
cd /var/www/irongroup
chmod +x manage_irongroup.sh

# 4. 更新数据
./manage_irongroup.sh update
```

**以后每周只需：**
```bash
ssh ubuntu@129.204.8.241
cd /var/www/irongroup
./manage_irongroup.sh update
```

---

### 方法2: 手动执行

```bash
# 1. SSH连接
ssh ubuntu@129.204.8.241

# 2. 进入目录
cd /var/www/irongroup
source venv/bin/activate

# 3. 运行同步
python sync_team_yahoo_simple.py irongroup.db oauth2.json

# 4. 重启服务
pkill -f "gunicorn.*irongroup"
nohup gunicorn --bind 127.0.0.1:5002 --workers 2 irongroup_app:app > irongroup.log 2>&1 &
```

## 🛠️ 管理脚本命令

上传管理脚本后，可以使用以下命令：

```bash
cd /var/www/irongroup

# 查看服务状态
./manage_irongroup.sh status

# 启动服务
./manage_irongroup.sh start

# 停止服务
./manage_irongroup.sh stop

# 重启服务
./manage_irongroup.sh restart

# 更新NHL/NBA数据
./manage_irongroup.sh update

# 查看实时日志
./manage_irongroup.sh log

# 备份数据库
./manage_irongroup.sh backup
```

## 🔧 常见问题

### Q: 网站打不开怎么办？

**A: 检查服务是否运行**
```bash
ssh ubuntu@129.204.8.241
cd /var/www/irongroup
./manage_irongroup.sh status
```

如果显示"服务未运行"，执行：
```bash
./manage_irongroup.sh start
```

---

### Q: 数据没有更新怎么办？

**A: 重新运行同步脚本**
```bash
ssh ubuntu@129.204.8.241
cd /var/www/irongroup
./manage_irongroup.sh update
```

---

### Q: 如何查看错误信息？

**A: 查看日志**
```bash
ssh ubuntu@129.204.8.241
cd /var/www/irongroup
./manage_irongroup.sh log
```

或者：
```bash
tail -50 /var/www/irongroup/irongroup.log
```

---

### Q: Yahoo OAuth过期了怎么办？

**A: 更新oauth2.json文件**

1. 在本地重新生成 oauth2.json（运行个人赛的认证脚本）
2. 用WinSCP上传到服务器
3. 覆盖 `/var/www/irongroup/oauth2.json`
4. 重启服务
