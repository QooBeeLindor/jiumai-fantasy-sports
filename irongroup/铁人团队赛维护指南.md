## 🔧 故障排查

### 问题1: 网站打不开（502错误）

**原因：** gunicorn服务没运行

**解决：**
```bash
ps aux | grep irongroup
# 如果没有进程，重启服务
cd /var/www/irongroup
source venv/bin/activate
nohup gunicorn --bind 127.0.0.1:5002 --workers 2 irongroup_app:app > irongroup.log 2>&1 &
```

---

### 问题2: NHL/NBA数据不更新

**原因：** Yahoo OAuth过期

**解决：**
```bash
cd /var/www/irongroup
# 检查oauth2.json文件是否存在
ls -la oauth2.json

# 如果需要，从本地上传新的oauth2.json
# 使用WinSCP上传
```

---

### 问题3: 数据库锁定

**错误信息：** "database is locked"

**原因：** 另一个进程正在访问数据库

**解决：**
```bash
# 查看是否有多个irongroup进程
ps aux | grep irongroup

# 如果有多个，杀掉所有
pkill -f "gunicorn.*irongroup"

# 重新启动一个
cd /var/www/irongroup
source venv/bin/activate
nohup gunicorn --bind 127.0.0.1:5002 --workers 2 irongroup_app:app > irongroup.log 2>&1 &
```

---

### 问题4: 服务器重启后服务没启动

**原因：** irongroup用nohup启动，不会自动重启

**解决方案1 - 手动启动：**
```bash
ssh ubuntu@129.204.8.241
cd /var/www/irongroup
source venv/bin/activate
nohup gunicorn --bind 127.0.0.1:5002 --workers 2 irongroup_app:app > irongroup.log 2>&1 &
```

**解决方案2 - 配置自动启动（推荐）：**
```bash
# 创建启动脚本
cat > /var/www/irongroup/start.sh << 'EOF'
#!/bin/bash
cd /var/www/irongroup
source venv/bin/activate
nohup gunicorn --bind 127.0.0.1:5002 --workers 2 irongroup_app:app > irongroup.log 2>&1 &
EOF

chmod +x /var/www/irongroup/start.sh

# 添加到crontab开机启动
crontab -e
# 添加这行：
@reboot sleep 30 && /var/www/irongroup/start.sh
```

```

    daily
    rotate 7
    compress
    missingok
    notifempty
}
```
